# Sonidos del juego

Coloca aquí los archivos de sonido en formato WAV o OGG.

## Archivos esperados

| Archivo | Descripción | Duración recomendada |
|---------|-------------|---------------------|
| `shoot.wav` | Disparo del jugador | 0.1 - 0.3 segundos |
| `enemy_shoot.wav` | Disparo de nave enemiga | 0.1 - 0.3 segundos |
| `explosion_asteroid.wav` | Explosión de meteorito | 0.3 - 0.5 segundos |
| `explosion_enemy.wav` | Explosión de nave enemiga | 0.3 - 0.5 segundos |
| `explosion_boss.wav` | Explosión del jefe final | 0.5 - 1.0 segundos |
| `powerup_collect.wav` | Recoger power-up | 0.2 - 0.4 segundos |
| `player_hit.wav` | Jugador recibe daño | 0.2 - 0.3 segundos |
| `level_transition.wav` | Transición de nivel | 1.0 - 2.0 segundos |

## Especificaciones técnicas

- **Formato**: WAV (preferido) o OGG
- **Frecuencia**: 44100 Hz
- **Bits**: 16-bit
- **Canales**: Mono (para efectos estéreo)
